# About CheeseScraper
Scrape and track cheese prices online. Cheese prices are periodically scraped from 3 stores, Walmart, Woolworths and Carrefour every week. Prices are stored for 7 weeks in order to record trends.

# Instruction
Download and install puppeteer:
```
npm install puppeteer
```

Then run
```
node index.js
```

The website should be hosted at `127.0.0.1:3000`.
